# 毛毛基金

给毛毛看的每日资产曲线。收益率来自 Robinhood 账户（通过 SnapTrade 只读拉取），
本金和加钱/取钱由我手工记账，人民币计价。

## 规则

- **每月保底 0.3%**：跑输就由我补足，展示曲线不会下跌
- **超额分成 50%**：跑赢保底的部分，我拿走一半
- 保底和分成都以**自然月**为结算单位。锚点每月重置，所以上个月已兑现的收益
  不会被这个月吃掉，这个月的分成也不会追溯上个月

## 两套现金流，绝对不能混

这是整个项目最容易算错的地方。

| | 来源 | 用途 |
|---|---|---|
| `brokerAdjustments` | `src/data/adjustment.json`，**手写**，美元 | 把账户总资产还原成**干净的收益率** |
| `fundCashFlows` | `src/data/cash-flows.json`，**手写**，人民币 | 给毛毛**发份额、算本金** |

账户里有我自己的钱进出（转账、Robinhood Gold 月费）。不剔除的话，
账户少 100 块会被算成一次亏损，毛毛的曲线就凭空掉一块。
反过来，毛毛的加钱是按当日净值买份额的，只增加等额的钱，不产生假收益。

**账户负责提供涨跌幅，我负责提供本金。**

## 两个口径也不能混

| 图 | 口径 | 为什么 |
|---|---|---|
| 托管账户 | **涨跌幅**：总资产 ÷ 开张那天的总资产 − 1，不剔资金 | 只吃 `account.json`，全自动，永远画到最新一天 |
| 毛毛的资产 | **时间加权**：逐日复利链，剔掉资金进出 | 她的钱分几次进来，只能按当日净值买份额 |

托管账户那条线**不剔除转账和月费**：它回答的是「账户里的钱比开张时多了多少」。
入金那天会有一段台阶，看着像暴涨 —— 口径本身如此，不是算错。要看干净收益率
就看毛毛那条。

## 资金流水台账

`src/data/adjustment.json` 是手写的，记我个人往托管账户里的转账和 Gold 月费，
单位美元，正数进、负数出：

```json
{ "date": "2026-08-14", "amount": -50, "notes": "转出 50 + Gold 月费 50，SoFi 入金 50" }
```

- **写当天的增量，不写累计余额。** 只修当天那一笔，之后的日子不受影响，
  也不用照抄
- **只影响毛毛那条曲线。** 托管账户走势图不看这个文件
- **不写就当成真实盈亏。** 漏一笔，毛毛的净值会把那笔转账算成涨跌，
  `npm run verify` 的「当期涨跌」列会冒出一个跟行情无关的大数
- 日期不落在快照日上也没关系，代码按区间归集到下一个快照

sync 只拉账户总资产，不拉券商活动列表 —— 失败又撤回的转账在活动列表里一条
都不留，这份台账只能手写。

## 命令

```bash
npm run dev               # 本地开发
npm test                  # 净值/保底/分成的单元测试
npm run verify            # 打印逐日对账表，人工核对
npm run snaptrade:sync    # 拉取账户数据 → src/data/account.json
npm run snaptrade:accounts # 列出已授权账户，确认 accountId
npm run snaptrade:connect  # 重新生成 Robinhood 授权链接（掉线时才用）
```

## 数据

- `src/data/account.json` — **脚本生成，别手改**。SnapTrade 返回的原始账户总资产
- `src/data/adjustment.json` — **手改这个**。托管账户里我个人的转账/月费（美元）
- `src/data/cash-flows.json` — **手改这个**。毛毛的加钱/取钱（人民币）

## 已知限制

- SnapTrade 的历史总资产是**隔日**粒度，且最多回溯 1 年。从今天起每天跑一次
  `snaptrade:sync` 才能积累出日粒度
- 账户 2026-07-15 之前是空的，算不出收益率。毛毛 6/26 就给钱了，
  这段空档在 `fundData.ts` 里补成「真实收益 0」，保底照给
- `getUserAccountReturnRates` 端点对这个账号未开通，收益率只能自己从总资产推
- **画不了 K 线**。账户历史每天只有一个 `total_value`，没有开高低收，
  蜡烛图缺三个数。账户走势图是折线，跟 Robinhood App 里那条一样
